# Тестирование

Каждый компонент проверялся отдельно своим скетчем (сервопривод: [`tests/servo_test`](../tests/servo_test/servo_test.ino)). Затем проверялась система целиком. Вывод в Serial Monitor на 9600 бод.

## Функциональные тесты

| Тест | Что проверяем | Ожидаемый результат |
|---|---|---|
| Открытие по пульту | нажатие кнопки в состоянии «Закрыт» | `[IR] Trigger`, `[MOVE] Start move to 90 (opening)`, ход 0°→90° с шагом 1° / 20 мс, светодиод мигает с периодом 150 мс, в конце `[MOVE] Movement finished`, привод отключён |
| Автозакрытие | через 5 с после открытия при `canClose = true` | `[AUTO] Closing`, ход 90°→0°, в конце состояние «Закрыт», светодиод погашен |
| Блокировка закрытия | `canClose = false` к моменту истечения таймера | `[AUTO] Close blocked`, шлагбаум остаётся открытым, таймер сброшен |
| Аварийное открытие | затенить/засветить фоторезистор во время закрытия | `[EMERGENCY] Obstacle detected! FAST OPEN`, быстрый подъём (5 мс/шаг), затем «Открыт» |
| Гистерезис | значения ≤150, ≥200 и от 151 до 199 | `canClose` меняется на границах и не меняется внутри диапазона |

## Периферия

- **Сервопривод.** Точно выходит в 0° и 90°, движется без рывков, после `detach` не дрожит и не греется.
- **ИК-приёмник.** Дальность до 8 м, угол около 90°. Повторные нажатия в состоянии «Открыт» и во время движения игнорируются (условие `!gateOpen && !moving`).
- **Фоторезистор.** Значения снимаются в Serial Monitor при разной освещённости и должны быть стабильны при постоянном свете.
- **Светодиод.** Мигает при любом движении, включая аварийное, и гаснет в покое.
