# Детерминированный конечный автомат

## Состояния

| Код | Состояние | Описание |
|---|---|---|
| S0 | Начальное | инициализация после включения питания |
| S1 | Закрыт | стрела опущена (0°), ожидание команды |
| S2 | Открывается | плавное движение вверх, светодиод мигает |
| S3 | Открыт | стрела на 90°, идёт таймер автозакрытия |
| S4 | Закрывается | плавное движение вниз |
| S5 | Аварийное открытие | быстрое движение вверх при запрете закрытия |

## События

| Код | Событие |
|---|---|
| x0 | запуск системы |
| x1 | команда с пульта |
| x2 | истёк таймер автозакрытия |
| x3 | запрет закрытия (препятствие, `canClose == false`) |
| x4 | достигнут целевой угол сервопривода |

## Таблица переходов

| | x0 | x1 | x2 | x3 | x4 |
|---|---|---|---|---|---|
| **S0** | S1 | | | | |
| **S1** | | S2 | | | |
| **S2** | | | | | S3 |
| **S3** | | S3 | S4 | | |
| **S4** | | | | S5 | S1 |
| **S5** | | | | | S3 |

Пустая ячейка означает, что событие в этом состоянии игнорируется. В S3 по x1 автомат остаётся в S3.

Если в S3 истёк таймер, но закрывать нельзя (`canClose == false`), автомат остаётся в S3 и таймер перезапускается (в логе `[AUTO] Close blocked`).

## Как автомат устроен в коде

Явной переменной состояния в скетче нет, состояние определяется комбинацией флагов:

| Состояние | `gateOpen` | `moving` | `closingNow` | `currentStepDelay` |
|---|---|---|---|---|
| Закрыт | false | false | — | — |
| Открывается | true | true | false | 20 мс |
| Открыт | true | false | — | — |
| Закрывается | false | true | true | 20 мс |
| Аварийное открытие | true | true | false | 5 мс |

## Гистерезис датчика

```
значение ≤ 150           →  canClose = true
значение ≥ 200           →  canClose = false
значение от 151 до 199   →  canClose не меняется
```
